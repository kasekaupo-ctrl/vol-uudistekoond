# Viljandimaa uudistekoond

WordPressi plugin Viljandimaa nelja omavalitsuse ja VOL-i uudiste koondamiseks.

Versioon: 1.1.5.

## Kasutamine

Lisa lehele lühikood `[vol_uudised]`. Seadistused asuvad menüüs **Seaded → Viljandimaa uudised**.

Paigaldus ja täpsemad valikud: [PAIGALDUS.md](PAIGALDUS.md).
